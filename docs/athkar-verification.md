## How to review

For each entry, check three things:

1. **النص** — wording and tashkeel match the printed source.
2. **العدد** — the repeat count matches the narration.
3. **الفضل** — where a virtue is stated, it is accurate and not
   overstated. Where it says «غير مذكور», nothing is claimed —
   that is deliberate, not an omission to be filled in casually.

Anything doubtful should have its `virtue` set back to `null` in
the JSON rather than reworded.
